## Run Locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

   On Windows:

   ```bash
   py -m http.server 8000
   ```

4. Visit http://localhost:8000.
5. Stop the server with `Ctrl+C`.

No npm installation or build is required. Google Fonts requires an internet connection; system fonts provide a fallback.

## Hosting

To publish through GitHub Pages:

1. Upload the website files and `images` folder to your portfolio repository.
2. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose **main** and **/ (root)**, then save.

Preserve relative asset paths, including `./images/srinivas.png`.
